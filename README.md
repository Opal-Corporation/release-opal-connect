## 🚀 About Opal Connect

Opal Connect is a high-performance desktop application engineered specifically for businesses that manage multiple WhatsApp accounts simultaneously. Built with modern Electron architecture, isolated session partitioning, and seamless web synchronization, it provides a centralized workspace to streamline your customer support, sales, and messaging operations.

## ✨ Key Features

#### 📱 **Multi-Account WhatsApp Workspace**
- **Isolated Multi-Session Partitioning**: Run multiple WhatsApp accounts concurrently with zero session crosstalk.
- **Side-by-Side Quick Switching**: Easily switch between accounts with a single click from the sidebar rail.
- **Unread Message Badges**: Real-time unread message counts displayed directly on session icons.
- **Session Customization**: Assign unique colors, initial avatars, and custom labels to each WhatsApp account.
- **Independent Cookie & Cache Storage**: Each session stores data in isolated disk partitions for maximum security.

#### 🔐 **Secure Authentication & Keyless Sync**
- **Browser Deep-Linking**: Sign in instantly via your web browser with single sign-on.
- **Keyless Web Data Sync**: Communicates securely with `connectopal.com` using user Bearer tokens without storing secret API keys on disk.
- **Subscription Tier Control**: Real-time enforcement for `Starter`, `Growth`, `Professional`, and `Enterprise` plans.
- **Expiration & Usage Locking**: Automatically locks access when plans expire or reach session capacity.

#### 💳 **Integrated Sri Lankan Billing (OnePay)**
- **Automated & Manual Payments**: Supports both recurring automatic billing and one-time manual checkout via OnePay.
- **LKR Currency Integration**: Native support for Sri Lankan Rupees with instant invoice generation.
- **Instant Activation**: Subscription status updates across web and desktop applications immediately upon payment verification.

#### 🔧 **Advanced & Desktop Features**
- **Automatic In-App Updates**: Built-in background update engine keeps your app current.
- **System Tray Integration**: Minimize to system tray for unobtrusive background operation.
- **Light & Dark Mode**: Beautiful, glassmorphic UI tailored for both dark and light desktop environments.
- **Live Statistics Footer**: Real-time tracking of active sessions, unread counts, and daily message metrics.

## 📥 Installation

### Download
1. Go to [Releases](https://github.com/Opal-Corporation/release-opal-connect/releases)
2. Download the latest `Opal Connect Setup X.X.X.exe` file
3. Run the installer (`Opal Connect Setup.exe`)
4. Follow the setup wizard

### Quick Start
1. **Launch Opal Connect** from your Desktop or Start Menu
2. **Sign in via Browser** using your `connectopal.com` account
3. **Click "Add Account"** to create a new WhatsApp Web session
4. **Scan the QR Code** with your phone's WhatsApp app
5. **Start managing** all your customer conversations in one unified desktop view!
